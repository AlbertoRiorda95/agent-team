# Design

- `project.md`: the project design, created by SETUP.md in a design studio session
  (from `_project-template.md`).
- `foundations.md`: in a new repository, the walking skeleton (structure, contract
  served, database, tests, green CI), written by SETUP.md and implemented first.
- `<feature>.md`: one spec per feature, from `_spec-template.md`, written in a design
  studio session (`docs/roles/design-studio.md`). Implementation starts only when
  the spec says `ready: yes`.
